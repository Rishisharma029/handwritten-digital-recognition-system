# Outputs

This directory stores all files generated by the Handwritten Digital Recognition System during runtime.

---

## Directory Structure

```text
outputs/
│
├── pdf/
│   └── Generated PDF documents
│
├── docx/
│   └── Generated Microsoft Word documents
│
├── txt/
│   └── Plain text exports
│
├── json/
│   └── OCR result JSON files
│
└── logs/
    └── Application log files
```

---

## Description

### pdf/

Contains OCR results exported as PDF documents.

Example:

```
invoice.pdf
notes.pdf
assignment.pdf
```

---

### docx/

Contains Microsoft Word (.docx) versions of OCR output.

Example:

```
notes.docx
essay.docx
```

---

### txt/

Stores plain text extracted from handwritten documents.

Example:

```
notes.txt
lecture.txt
```

---

### json/

Contains structured OCR data.

Example:

```json
{
    "filename": "notes.jpg",
    "engine": "TrOCR",
    "confidence": 98.45,
    "language": "English",
    "text": "Hello World"
}
```

---

### logs/

Stores application logs.

Example:

```
ocr.log
```

---

## Generated Automatically

The application automatically creates these folders if they do not already exist.

No manual setup is required.

---

## Notes

- Do not store important files here permanently.
- These folders contain runtime-generated files.
- Large generated files should not be committed to Git.
- Add generated output folders to `.gitignore` if necessary.
